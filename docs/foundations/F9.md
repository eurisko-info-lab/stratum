# F9 — constituted agreement and settlement

```text
federation: add BFT finality and equivocation evidence in F9
```

## Feature

The single publication authority is replaced by a constituted federation.

$$
F_9 = F_8 + \text{constituted agreement and settlement}
$$

## Meta change

[features/federation/federation.meta](../../features/federation/federation.meta)
declares `Replica`, `ReplicaSet`, `AgreementProposal`, `Vote`,
`FinalityCertificate`, `ViewChange`, `FederationState`, `EquivocationEvidence`
and `FederationTransition`, with the judgments `ValidateProposal`,
`ValidateVote`, `ValidateCertificate`, `ValidateTransition`,
`ReplayFinalizedHistory` and `DetectEquivocation`.

## The ordering rule

$$
\boxed{\mathsf{SemanticValidity}\ \text{before}\ \mathsf{Agreement}}
$$

`CastVote` refuses to sign until `SemanticallyValid` holds: the proposed
successor must be compatible with the declared predecessor under the selected
foundation. A replica that is asked to endorse an incompatible transition
returns `(abstained semantically-invalid)`.

## Membership and thresholds

Classic $3f+1$ membership: with $n$ replicas, $f = \lfloor (n-1)/3 \rfloor$ and
the agreement threshold is $n - f$. For the four-replica set in the scenarios the
threshold is three.

Membership changes are governed transitions: `ChangeMembership` only applies
after a settled history.

## Native boundary

The host supplies authenticated transport, signature primitives and durable
message storage. The agreement state machine, certificate meaning and transition
validity are Meta programs.

## Rejections

| Rejection | Reason |
| --- | --- |
| certificate does not bind the proposal | `certificate-for-another-proposal` |
| fewer endorsements than the threshold | `insufficient-quorum` |
| certificate or proposal names another federation | `wrong-federation` |
| endorsement signature does not verify | `bad-vote-signature` |
| endorser is not a member | `unknown-voter` |

## Equivocation

`DetectEquivocation` reports `EquivocationEvidence` when one replica endorses two
different subjects in the same view and slot.

## Proof obligations

proves the derivation relation is functional, which is what makes replay of a
fixed settled history reproducible on independent replicas.
