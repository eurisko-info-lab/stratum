# F3 — local causal semantic repository

```text
repo: add causal patch graphs and branches in F3
```

## Feature

A local Pijul-like semantic repository. There is still no network and no
publication ledger.

$$
F_3 = F_2 + \text{local causal semantic repository}
$$

## Meta change

[features/repository/repository.meta](../../features/repository/repository.meta)
declares `Patch`, `PatchConflict`, `Repository`, branch membership, topological
ordering and replay.

A patch carries semantic changes and causal dependencies. Its identity is

$$
\mathsf{id}(p) = H(\mathsf{encode}(\texttt{(patch-content deps changes)}))
$$

so it never depends on a mutable branch name. A branch is a membership set over
the patch graph, never a copied snapshot.

## Grammar change

Repository commands: `branch`, `record`, `apply`, `unapply`, `merge`, `resolve`,
`log`, `diff`, `heads`, `dependencies`.

## Replay is the only source of state

$$
\mathsf{Replay}(R, h) = S
$$

is deterministic: `TopoOrder` always emits the least ready patch identity next,
so the recording order of independent patches cannot affect the result. A patch
never declares its resulting snapshot.

## Conflicts

`ReplayTolerant` continues past a conflicting patch and returns

```text
(replayed <state> [(PatchConflict <identity> <reason>) ...])
```

Conflicts are canonical artifacts. A resolution is an ordinary patch that
depends on both sides and is authored against the observed conflicted state.

## Unrecord

`UnapplyPatch` removes a patch from branch membership. The patch remains in
`Repository'patches`, so history is never deleted.
