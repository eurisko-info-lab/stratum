# F2 — generic semantic change calculus

```text
changes: derive free change languages in F2
```

## Feature

Bootstrap whole-value replacement is superseded by generic structural free
changes derived from descriptions.

$$
F_2 = F_1 + \text{generic semantic change calculus}
$$

## Meta change

[features/change/change.meta](../../features/change/change.meta) declares the
universe of structural descriptions and the change calculus:

```text
Desc = DAny | DRecord | DSum | DMap | DKeyedList | DList
```

$$
\mathsf{FreeChange} : \mathsf{Desc} \to \mathsf{Desc}
\qquad
\mathsf{Apply} : \mathsf{El}(D) \times \mathsf{El}(\mathsf{FreeChange}(D)) \to \mathsf{El}(D)
$$

## Grammar change

Change syntax addresses semantic identities: `fieldId`, `constructorId`, `key`,
`path`, `insert`, `delete`, `replace`, `rename`, `edit`. A path is a list of
`(field n)`, `(constructor t)` and `(key k)` steps. No path is a source offset
and no path is a bare list position, so field edits survive reformatting and
keyed edits survive reordering.

## Change witness

`WitnessFor(desc)` produces the record

```text
FreeChangeWitness {
  sourceDescription  changeDescription  applyProgram
  identityProgram    compositionProgram independenceProgram  conflictProgram
}
```

## Derived languages

`DeltaMeta1`, `DeltaGrammar1`, `DeltaLambda` and `DeltaFoundation` are all
`FreeChange` applied to the corresponding description. They are derived, not
authored.

## Laws

$$
\mathsf{Apply}(x, \mathsf{identity}) = x
$$

$$
\mathsf{Apply}(\mathsf{Apply}(x,a),b) = \mathsf{Apply}(x, \mathsf{compose}(a,b))
$$

$$
a \perp b \iff \mathsf{paths}(a) \cap \mathsf{paths}(b) = \emptyset
$$

Independent changes commute. Overlapping incompatible changes produce a
canonical `(conflict <reason>)` artifact, never a host exception.
