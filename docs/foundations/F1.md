# F1 — self-described Meta and Grammar

```text
meta: self-describe Meta and Grammar in F1
```

## Feature

Meta and Grammar stop being host artifacts and become ordinary languages
interpreted by the bootstrap machines.

$$
F_1 = F_0 + \text{self-described Meta and Grammar}
$$

## Meta change

[languages/meta/meta.generated.grammar](../../languages/meta/meta.generated.grammar) declares the
Meta surface: `module`, `import`, `capability`, `evidence`, `mode`, `measure`,
`data`, `record`, `judgment`, `rule`, patterns and expressions.

[languages/meta/elaborate.meta](../../languages/meta/elaborate.meta) elaborates
Meta to canonical Meta0. `data` declarations become constructor judgments plus a
recogniser, `record` declarations become a constructor plus accessors, `rule`
groups become ordered `match` cases, and modes, measures, capabilities and
evidence become queryable metadata judgments.

## Grammar change

[languages/grammar/grammar.generated.grammar](../../languages/grammar/grammar.generated.grammar)
declares the Grammar surface: `grammar`, `start`, `token`, `category`, `prod`,
`pass`, `fold`, `paren`, keyword elements and `field : target` bindings.
[languages/grammar/elaborate.meta](../../languages/grammar/elaborate.meta)
elaborates Grammar to canonical Grammar0.

## Self-description

| Step | Evidence |
| --- | --- |
| load Meta from artifacts | `meta` grammar in the F1 closure |
| parse Meta's own source | `meta-parse-print-roundtrip` |
| reconstruct the canonical Meta AST | `elaboration-stable-under-printing` |
| load Grammar | `grammar` grammar in the F1 closure |
| parse Grammar's own grammar | `grammar-describes-itself` |
| reconstruct its canonical grammar AST | digest equality with the committed artifact |
| reconstruct the lambda language | `lambda-grammar-reconstructs`, `lambda-program-fixpoint` |
| derive the same lambda behaviour as F0 | the F0 lambda checks, rerun under F1 |

Grammar parses its own grammar and elaborates to exactly the committed
`grammar.grammar` artifact; Meta's grammar is likewise reconstructed from
Grammar source. This is the fixpoint

$$
\mathsf{Meta0}(\mathsf{Meta}) = \mathsf{Meta}
$$

at the canonical artifact level, checked by `lambda-program-fixpoint` against the
committed elaboration output.

## The lambda language is reconstructed, not re-authored

F1 does not load [languages/lambda/lambda.bootstrap.meta](../../languages/lambda/lambda.bootstrap.meta).
It loads [languages/lambda/lambda.generated.meta](../../languages/lambda/lambda.generated.meta),
elaborated from [languages/lambda/lambda.meta](../../languages/lambda/lambda.meta),
and [languages/lambda/lambda.generated.grammar](../../languages/lambda/lambda.generated.grammar),
elaborated from [languages/lambda/lambda.grammar](../../languages/lambda/lambda.grammar).
The generated grammar has the same digest as F0's hand-written grammar artifact.

Regenerate with:

```bash
./tools/regenerate.sh
```

## Native freeze gate

From this commit onward Meta0 and Grammar0 are immutable, Meta and Grammar
evolve through their own change languages, and no feature may introduce host
semantic logic. Enforced by
[test-scala/NativeBoundarySuite.scala](../../test-scala/NativeBoundarySuite.scala).
