# F6 — self-hosted application and foundation protocol

```text
foundation: package self-hosted applications and successors in F6
```

## Feature

Complete systems become ordinary applications and foundations. This commit
closes the first full self-hosting staircase step.

$$
F_6 = F_5 + \text{self-hosted application and foundation protocol}
$$

## Meta change

[features/foundation/foundation.meta](../../features/foundation/foundation.meta)
declares `ApplicationManifest`, `FoundationManifest`, `MachineProfile`,
`RuntimeProfile`, `EvidenceProfile`, `CompatibilityWitness`, `FoundationChange`
and `SuccessorFoundation`.

## Verification interface

A host verifies a foundation from

```text
foundation digest
+
closure
```

`VerifyRoot` consumes a reference and reads only the closure. `VerifyClaimed`
exists solely to reject an attempted override: if the offered manifest differs
from the artifact in the closure the result is
`(invalid host-override-rejected)`.

## Independent reconstruction

[host-rust](../../host-rust) is a second bootstrap host written from scratch with
no dependencies. It implements SHA-256, canonical decoding with canonicity
rejection, artifact envelopes, closure traversal, foundation structure checking
and canonical verdict emission.

Both hosts emit the same attestation:

$$
\mathsf{Canon}(\mathsf{ScalaVerify}(F_6)) = \mathsf{Canon}(\mathsf{RustVerify}(F_6))
$$

```bash
cd host-rust && cargo build --release
./host-rust/target/release/stratum-verify attest foundations/F6
sbt "runMain stratum.cli.Stratum foundation attest --dir foundations/F6"
```

[test-scala/HostParitySuite.scala](../../test-scala/HostParitySuite.scala)
compares the two outputs whenever the independent host has been built.

**Scope of the parity gate.** The attestation covers canonical decoding,
identity, closure completeness and manifest structure. It does not yet compare
MetaMachine0 derivations across hosts: the independent host implements the
verification interface, not the full derivation engine.
