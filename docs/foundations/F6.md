```text
foundation: package self-hosted applications and successors in F6
```

## Feature

Complete systems become ordinary applications and foundations. This commit
closes the first full self-hosting staircase step.

$$
F_6 = F_5 + \text{self-hosted application and foundation protocol}
$$

## Verification interface

A host verifies a foundation from

```text
foundation digest
+
closure
```

`VerifyRoot` consumes a reference and reads only the closure. `VerifyClaimed`
exists solely to reject an attempted override: if the offered manifest differs
from the artifact in the closure the result is
`(invalid host-override-rejected)`.

## Independent reconstruction

[host-rust](../../host-rust) is a second bootstrap host written from scratch with
no dependencies. It implements SHA-256, canonical decoding with canonicity
rejection, artifact envelopes, closure traversal, foundation structure checking
and canonical verdict emission.

Both hosts emit the same attestation:

$$
\mathsf{Canon}(\mathsf{ScalaVerify}(F_6)) = \mathsf{Canon}(\mathsf{RustVerify}(F_6))
$$

```bash
cargo build --release --manifest-path host-rust/Cargo.toml
./tools/parity.sh
```

[test-scala/HostParitySuite.scala](../../test-scala/HostParitySuite.scala)
compares the two outputs whenever the independent host has been built, and fails
rather than skips when `STRATUM_REQUIRE_RUST=1` is set, which CI does.

**Scope of the parity gate.** The two hosts agree on canonical decoding and
rejection, identity, closure completeness, manifest structure, the frozen host
core identity, and every canonical verdict produced by MetaMachine0 including
its evidence and its deterministic resource accounting. What is not yet shared
is the capability adapter surface: the independent host implements the adapters
the foundations actually request, and the freeze deliberately permits adapters
to differ.

## Lean model

[verifier-lean/Stratum/Meta0.lean](../../verifier-lean/Stratum/Meta0.lean) models
the actual Meta0 program language: canonical values, the expression and pattern
forms carried as data, the environment, the judgment table, the explicit step
budget and the canonical verdict. It proves that derivation and its resource
accounting are functions of their inputs, that pattern matching is
deterministic, and that a zero budget always yields the canonical exhaustion
verdict. Capability requests are outside the model: they are constituted by the
Kernel rather than by the calculus.
[verifier-lean/Stratum/Bootstrap.lean](../../verifier-lean/Stratum/Bootstrap.lean)
keeps the smaller relational statement. The toolchain is pinned in
[verifier-lean/lean-toolchain](../../verifier-lean/lean-toolchain).
