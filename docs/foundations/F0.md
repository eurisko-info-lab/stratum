seed: create F0 Scala lambda foundation

## Feature

The minimal Scala bootstrap and one local untyped lambda-calculus world. This is
the only foundation authored directly in Scala.

$$
F_0 = \text{local untyped lambda calculus over canonical artifacts}
$$

## Native implementation

[host-scala](../../host-scala) provides `Canon`, `Digest`, `Artifact`,
`LocalCas`, `Closure`, `MetaMachine0`, `GrammarMachine0`, `Budget`, `Evidence`,
`CapabilityRequest`, `CapabilityResponse` and the bootstrap foundation manifest
handling. Capability handlers cover local filesystem access, CAS access and
hashing, plus the generic grammar machine surface.

## Canonical language artifacts

[languages/lambda/lambda.bootstrap.grammar](../../languages/lambda/lambda.bootstrap.grammar) declares
the surface:

```text
x
\x. body
function argument
(function) argument
```

[languages/lambda/lambda.bootstrap.meta](../../languages/lambda/lambda.bootstrap.meta) declares the
judgments `ToDeBruijn`, `FromDeBruijn`, `Shift`, `Substitute`, `Beta`,
`StepNormalOrder`, `Normalize`, `AlphaEquivalent` and `FreeVariables`.
Substitution and alpha-equivalence are deterministic because evaluation happens
on a de Bruijn representation with free variables kept named.

## Bootstrap changes

[languages/foundation/foundation.meta](../../languages/foundation/foundation.meta)
provides the predecessor-bound replacement change:

```text
ReplaceChange { targetKey, expectedBefore, replacement }
```

`ApplyReplace` rejects a replacement whose expected predecessor value does not
match, so a change can never silently overwrite a different value.

## Local history

`FoundationRoot { predecessor, application, meta, grammar, closure }` with
`HistoryValid` checking the predecessor links. There are no named branches, no
patch graphs, no networking, no publication, no signatures and no agreement
protocol at this step.
