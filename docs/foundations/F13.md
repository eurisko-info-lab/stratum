# F13 — canonical schema reflection and structural change law

```text
schema: separate schema constitution from semantic-fs and make identity, versioning, and change first-class
```

## Feature

F13 introduces an explicit schema layer with canonical reflection, stable
schema identity and versioning, derived codecs and references, and a structural
change language with migration laws.

$$
F_{13} = F_{12} + \text{canonical schema reflection and structural change law}
$$

## What changed

1. Canonical schema reflection is explicit and host-visible.
2. Schema identities and versions are first-class values.
3. Codecs and reference traversals are derived from declared schema shape.
4. Structural change is expressed as a language over schema shape.
5. Migration laws define when changes compose, commute, or conflict.

## Interpretation

Schema constitution is no longer implicit inside semantic-fs behavior. It is a
separate layer that later abstractions can depend on directly.

## Result

$$
F_{13} = F_{12} + \text{canonical schema reflection and structural change law}
$$
