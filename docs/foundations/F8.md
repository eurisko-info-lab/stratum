# F8 — distributed closure and branch synchronization

```text
sync: add closure and branch synchronization in F8
```

## Feature

Peer-to-peer synchronization without an agreement protocol.

$$
F_8 = F_7 + \text{distributed closure and branch synchronization}
$$

## Meta change

[features/sync/sync.meta](../../features/sync/sync.meta) declares
`PeerIdentity`, `ClosureOffer`, `ClosureNeed`, `BranchAdvertisement`,
`ChainAdvertisement`, `FetchPlan` and `SyncTranscript`.

## Native boundary

The host gains only generic transport:

```text
Send(peer, bytes)   Receive(channel)   OpenConnection(peer)   CloseConnection(peer)
```

Message schemas, negotiation, closure selection and validation remain Meta-level
features.

## Behaviour

- exchange is digest addressed: a store is a map from digest to value
- `NeededDigests` discovers missing objects by set difference
- `RemainingPlan` makes a transfer resumable from whatever the target already has
- `AcceptArtifact` verifies every artifact against the digest it was requested
  by, so corrupted bytes are rejected rather than stored
- branch frontiers and chain heads are exchanged as canonical advertisements
- `IntegrateRemote` returns proposals: no remote patch is ever added to branch
  membership automatically

## Offline workflow

A local repository remains usable without a network. Synchronization updates
available closures and frontiers; it never replaces local semantic replay.
