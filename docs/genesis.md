# Genesis

The genesis campaign packages Stratum as a canonical application and foundation
that Cairn can verify from digests and closure alone.

This repository reserves the required artifact paths:

- `genesis/application.canon`
- `genesis/foundation.canon`
- `genesis/closure/`
- `genesis/expected-verdicts.canon`
- `genesis/adversarial/`

The committed files are placeholders until the locked Cairn bootstrap release
publishes the canonical seed, host digests, and test vectors needed to replace
them with real content-addressed artifacts.
